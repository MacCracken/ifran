# ifran — 2.0 Security / Hardening Audit (2026-07-05)

> Pre-cut audit of the ported control plane (M0–M6, ~1.9k lines of Cyrius):
> spec parsers, the executor, the stores (model/dataset/preference), key
> handling, and the metric extractor. Method: manual derive-from-source pass
> over each module against the threat model in `SECURITY.md`. **PASS — 0 code
> changes**; the trust posture is delegation to already-audited surfaces plus
> operator-authored input.

## The central posture

ifran's inputs are (a) **operator-authored specs** (bayan TOML — not hostile
input; malformed → clean reject and nothing spawns), (b) **potentially foreign
artifacts** (delegated whole to tula's frozen, fuzzed validator + sigil
Ed25519 — ifran never parses artifact bytes itself), and (c) **child process
output** (bounded capture, never evaluated). Every DB write goes through patra
prepared statements with bound parameters.

## Per-surface findings (all clean)

- **Executor** (`run.cyr`): argv → `execve` directly — no shell, no injection
  path through args or dataset paths; absolute-bin enforced at parse; capture
  bounded at 4 MB with an explicit truncation marker; exit-code recovery
  handles exec-fail (127) and signals (128+n); pipe fds closed on all paths.
- **Key handling** (`keys.cyr`): getrandom-backed seed (short-read looped);
  secret written via 0600 open; no-clobber; the secret never prints (only the
  pk hex does).
- **Model store** (`store.cyr`): validate-before-everything (tula_open on the
  mmap'd file); sig status honest, never inflated; content hash re-derived on
  verify; the store path is derived from the hash, not attacker-controlled
  names.
- **Datasets / prefs** (`dataset.cyr` / `pref.cyr`): content stored as bytes;
  stats are counting loops over mapped buffers; dedup's map_u64 keys remap the
  two sentinel values (0/−1); JSONL export escapes via the stdlib JSON escaper
  (suite proves quote round-trip).
- **Metric extractor** (`eval.cyr`): bounded scan of the mapped log for a
  numeric token; returns a copied token; no interpretation.
- **Spec parsers** (`jobspec.cyr` / `sweep.cyr` / `eval.cyr`): bayan does the
  TOML; every missing/invalid field is an explicit reject-with-message;
  `bayan_toml_parse_file` returns an EMPTY VEC (not 0) for missing files —
  callers route through the section check, which handles it (verified).

## Known, documented limitations (not defects)

- No job timeout — a hung child hangs `ifran run` (nothing else); the
  reaper/timeout is the named scheduler follow-on.
- Space-split args (no quoting) — spec-authoring limitation, documented in the
  CLI reference.
- Table listings do client-side kind-counting — fine at single-operator
  scale; revisit if the store grows aggregates.

## Standing guidance for 2.x

New input surfaces follow the anukūlana rule: wrap-safe bounds + null-checked
allocs + fuzz-in-the-same-cut for anything that parses NON-operator bytes.
Today ifran parses none itself (tula/bayan/patra own their formats) — keep it
that way where possible.
